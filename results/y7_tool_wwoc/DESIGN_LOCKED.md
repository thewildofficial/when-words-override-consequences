# Y7 design: WWOC contrarian game as tool use (locked before run, ~05:15 IST Oct 29; user direction 05:10 "tool use to demonstrate WOOC")
Construct: the original project question (do represented consequences steer the chosen action when the action's wording points the other way?), with the action emitted as a tool call instead of an A/B letter. Simulated tools, known deterministic payoffs: the contrarian receiver policy is stated exactly, payoff is 10 if the receiver ends at the target response. No real external actions.
Items: 32 FRESH base games (ids 200-231; the frozen RBG-4 set used base games 0-23, config base_games=24), strategic frame, OPPOSED incentive only, history none/redundant x mapping prose/table x formats: (1) ab_assertion and ab_opaque: the frozen RBG-4 prompt unchanged (256 rows, replication of the A/B effect on fresh games); (2) tool_assertion_name: tools named claim_state_<concept> (wording in the tool NAME and description); (3) tool_assertion_desc: tools named action_a/action_b with the wording only in the description; (4) tool_opaque: tools named send_<token>, opaque tokens (128 rows each). 640 rows.
Readout: forced-choice score = sum log-prob of each tool's name (+'>') after the assistant prefill '<tool_call>\n<function=' (Qwen3.6 tool-call format read from its chat template); choice = higher score. Continuations are tokenised separately from the context (same for both candidates). Syntax gate: greedy free generation on 64 tool rows, report well-formed/ill-formed and agreement with forced-choice. Expected tool = the one whose stated consequence yields the target response; realised payoff = 10 if chosen tool induces the target, else 0.
Gates (interpretation only): tool_opaque accuracy >= 90% and syntax gate >= 90% well-formed on free generation; otherwise tool-format interpretation is blocked.
Predictions (hypotheses): ab_opaque ~100%; ab_assertion/prose/redundant well below 60% (RBG-4: 27% prose, history); tool_opaque >=90%; tool_assertion_name below tool_opaque, with the prose/redundant cell the lowest; tool_assertion_desc between them if the name matters more than the description. A table format removes the history harm (RBG-4). If tool_assertion_name stays at ~opaque, the effect is specific to A/B letters and not general to action emission. The experiment cannot say which internal quantity causes any gap.
Counts per cell are 32 games (cluster = base game); report per-cell k/32 with Wilson CIs, and within-game paired differences. Est cost ~$0.5 (640 short forwards + 640x2 name-scoring forwards + 64 generations). Running total after ~ $6.6 (Y6 ~$0.5 still to be added).
